ดึงรูปทั้งหมดออกจาก Supabase Storage

รวมเป็นไฟล์ zip ไฟล์เดียว พร้อม manifest.json บอกว่าไฟล์ไหนคู่กับกล้องตัวไหน

ต้องกู้บริการ Supabase ก่อนใช้เครื่องมือนี้
ตัวไฟล์รูปอยู่ใน S3 ไม่ได้อยู่ใน Postgres จึงต้องเรียกผ่าน Storage API ซึ่งตอนโปรเจกต์ถูกระงับจะตอบ 402 ทุกคำขอ
ลองก่อนได้เลย — ถ้าขึ้น 402 คือยังไม่ได้กู้บริการ
